## Projet d'articulation et workflow Git/GitHub

D'ici peu, vous allez commencer à travailler sur votre projet d'articulation.
Voici quelques conseils pour vous aider à démarrer :

- Mettez en place un workflow Git/GitHub efficace pour votre projet dès le
  départ.
- Utilisez les Issues/PRs/Validation pour organiser votre travail et faciliter
  la collaboration.
- GitHub offre plein de fonctionnalités que nous n'avons pas eu le temps
  d'explorer pour gérer votre projet. N'hésitez pas à les utiliser !

## Lavarel et frameworks réactifs

Laravel peut être utilisé avec [Inertia.js](https://inertiajs.com/) pour
utiliser un framework JavaScript moderne (comme React, Vue ou Svelte) pour
construire l'interface utilisateur de votre application. Cela permet de
bénéficier de la puissance de Laravel pour le backend et JavaScript pour le
frontend, tout en gardant une expérience de développement fluide.

De plus, Laravel propose également [Livewire](https://laravel-livewire.com/)
pour construire des interfaces utilisateur dynamiques sans avoir à écrire de
JavaScript.

D'autres technologies comme [Laravel Filament](https://filamentphp.com/)
permettent de construire des interfaces d'administration rapidement et
facilement.

## Starter kits Laravel

Nous n'avons que effleuré les possibilités offertes par Laravel. Si vous
souhaitez aller plus loin, Laravel propose ce qu'on appelle des "starter kits"
pour vous aider à démarrer rapidement avec des fonctionnalités préconfigurées
telles que l'authentification, les équipes, etc.

Les starter kits permettent de démarrer un projet Laravel avec des
fonctionnalités courantes déjà mises en place, ce qui peut vous faire gagner du
temps et vous permettre de vous concentrer sur les aspects spécifiques de votre
application.

## Déplacer vos mini-projets sur votre compte GitHub personnel (2)

Si vous souhaitez, vous pouvez déplacer vos mini-projets vers votre compte
personnel pour les conserver après la fin du cours.

Pour cela, allez dans les paramètres de votre dépôt GitHub, puis dans la section
"Danger Zone", vous trouverez une option pour transférer le dépôt vers un autre
compte.

Cela permettra de garder une trace de votre travail et de montrer vos
réalisations à des employeur.euses potentiel.les.
